# Notes

Use this folder for study notes organized by source and purpose:

- [`books/`](books/README.md): notes scoped to a specific book and edition.
- [`sites/`](sites/README.md): notes and references from websites or articles.
- [`ideas/`](ideas/README.md): your own insights that connect ideas across
  sources.

Book notes can use LaTeX; site notes and personal ideas can use Markdown.
