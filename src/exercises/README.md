# Exercises

LeetCode-style solutions that validate the data structures, algorithms, and
strategies in this crate.

## Organization

- `easy`: foundational problems with direct implementations.
- `medium`: problems that usually combine multiple ideas.

Hard exercises can be added once enough supporting structures and strategies
exist.

## Exercise Rule

Each exercise should expose a small `solve` function and keep problem-specific
logic local. Shared logic should live in `dsa`, `algorithms`, or `strategies`.

## Starting Goals

1. Two Sum.
2. Valid Anagram.
3. Reverse Linked List.
4. Maximum Depth of Binary Tree.
5. Binary Tree Level Order Traversal.
6. Implement Trie.
7. Number of Islands.
8. Coin Change.
