# Recursion In Rust

Notes and goals for recursive problem solving.

## Core Concepts

- Define the base case before the recursive step.
- Borrow inputs when recursion does not need ownership.
- Prefer slices over index pairs for simple recursive array problems.
- Watch stack depth on large inputs; convert to iteration when needed.

## Implementation Goals

1. Countdown.
2. Factorial.
3. Sum array.
4. Count elements.
5. Recursive binary search.
6. Find maximum.
7. Tree depth.

## Exercise Goals

1. Maximum Depth of Binary Tree.
2. Same Tree.
3. Invert Binary Tree.
4. Subsets.
5. Permutations.
6. Combination Sum.
