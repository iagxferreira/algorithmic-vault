# Data Structures

Core data structures implemented from scratch in Rust.

## Current Modules

- `binary_tree`: owned tree nodes, depth, and level-order traversal.
- `linked_list`: singly linked list helpers and reversal.
- `union_find`: disjoint set union with path compression and rank.

## Rust Focus

- Prefer clear ownership over clever abstractions.
- Use `Option<Box<T>>` for recursive owned structures.
- Use slices and references for read-only algorithms.
- Keep mutation explicit and covered by edge-case tests.
