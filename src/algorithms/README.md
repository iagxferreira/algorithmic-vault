# Algorithms

Reusable algorithm implementations that are not tied to one concrete exercise.

## Current Modules

- `arrays`: array and hash-map helpers.
- `search`: binary search.
- `sorting`: elementary sorting algorithms.

## Study Goals

1. Start with direct, readable implementations.
2. Test empty, singleton, duplicate, sorted, and reverse-sorted inputs.
3. Prefer generic implementations only after the `i32` version is correct.
4. Document time and space complexity when an algorithm becomes non-trivial.

## Next Algorithms
