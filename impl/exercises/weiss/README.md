# Data Structures and Algorithm Analysis in C++ (Weiss)

Scaffolding for exercises from *Data Structures and Algorithm Analysis in C++*
by Mark Allen Weiss. Each chapter gets a folder with one subfolder per
programming exercise. Exercise statements live in each folder's `README.md`, and
the corresponding study notes live in
[`notes/booknotes/data-structures-and-algorithm-analysis-in-cpp/`](../../../notes/booknotes/data-structures-and-algorithm-analysis-in-cpp/README.md).

Solutions are intentionally left unimplemented: `main.cpp` is a stub and each
folder's `README.md` lists the requirements and a checklist. Build a stub with:

```sh
make -C impl/exercises/weiss/chapter-01/01-selection-problem run
```
